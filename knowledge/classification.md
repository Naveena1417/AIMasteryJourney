# Classification

Classification is a supervised machine learning problem.

The goal is to predict a categorical target.

Examples:

- Spam or Not Spam
- Disease or No Disease
- Purchased or Not Purchased

Common classification algorithms:

- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost
- Support Vector Machine

Common evaluation metrics:

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC
